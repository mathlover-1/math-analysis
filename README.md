# 数学分析习题整理

> 一份在南京大学一年级数学分析学习过程中逐步积累形成的笔记式习题整理，供复习、查阅与二次整理使用。

本书按数学分析课程的学习顺序编排，选取较有难度、方法典型或思路新颖的题目，保留推导过程与解题思路。它是持续修订的学习资料，并不追求覆盖数学分析的全部知识点。

[阅读整书 PDF](数学分析习题整理.pdf)

## 内容概览

- **第一章·数列**：数列收敛、单调性与有界性、递推数列、上下极限及极限估计。
- **第二章·实数系基本定理**：实数完备性的不同表述、基本定理之间的互推与应用。
- **第三章·函数**：连续性、一致连续性、单侧极限、单调性、间断点与周期性。
- **第四章·一元微分学与一元积分学**：中值定理、导数估计、积分与零点问题。
- **第五章·多元微分学与多元积分学**：多元函数的微分、极值与凹性，曲线和曲面积分，以及 Gauss、Green、Stokes 公式的应用。
- **第六章·级数**：已收录部分数项级数习题，仍在编写中。
- **第七章·Fourier 分析**：目前为占位章节，尚未收录正式题目。
- **附录·数学分析重要定理**：第 1 节依次整理不等式、欧几里得空间、集合与映射；第 2 至 8 节按课程顺序整理相关定义、命题与定理，并为部分核心结论附证明。

## 题目与解答标记

- `【题x】`：普通题目；`【拓展1】`、`【拓展2】`：相关定理或证明方法的扩展。
- **证明**：主要解答；**另解**：可以独立完成论证的另一种方法。
- **注**、**注记**：就近补充条件、记号、结论或思考动机。
- **一点思考**：记录思考动机或试探过程，不替代严格证明。
