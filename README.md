# 数学分析习题整理

> 一份在南京大学一年级数学分析学习过程中逐步积累形成的笔记式习题整理，供复习、查阅与二次整理使用。

全书按数学分析课程的学习顺序编排，选取较有难度、方法典型或思路新颖的题目。它包含**两个可独立使用的版本**：

- **正书**：题目 + 推导与解答 + 书末附录《数学分析重要定理》，用于系统复习与查阅；
- **纯习题册**：只保留题目与前辅文，删去全部解答与附录，并在每题之后按原解答的篇幅留出书写空白，用于独立练习与自测。

两个版本各自独立成书、独立编译，章节结构一致。

## 目录结构

```
.
├── README.md
├── 正书/         # 题目 + 解答 + 附录（133 页）
└── 纯习题册/     # 仅题目，题后留白（36 页）
```

两本册子的文件名一一对应（母文件、导言、第一至第八章），区别只在于：正书多出四个附录分片，且各章文件内含解答。

## 正书

[阅读整书 PDF](正书/数学分析习题整理.pdf)

- **第一章·数列**：数列收敛、单调性与有界性、递推数列、上下极限及极限估计。
- **第二章·实数系基本定理**：实数完备性的不同表述、基本定理之间的互推与应用。
- **第三章·函数**：连续性、一致连续性、单侧极限、单调性、间断点与周期性。
- **第四章·一元微分学与一元积分学**：中值定理、导数估计、积分与零点问题。
- **第五章·多元微分学与多元积分学**：多元函数的微分、极值与凹性，曲线和曲面积分，以及 Gauss、Green、Stokes 公式的应用。
- **第六章·级数**：数项级数的收敛性判别、一致收敛与幂级数等，已收录 19 题，仍在编写中。
- **第七章·Fourier 分析**：目前为占位章节，尚未收录正式题目。
- **第八章·含参变量积分**：目前为占位章节，尚未收录正式题目。
- **附录·数学分析重要定理**（共 9 节）：第 1 节依次整理不等式、欧几里得空间、集合与映射；第 2 至 9 节按课程顺序整理相关定义、命题与定理；第 9 节精选梅加强《数学分析》第二版第十五章的核心结论，并为部分核心结论附证明。

## 纯习题册

[阅读整书 PDF](纯习题册/数学分析纯习题册.pdf)

- **收录范围**：第二版前言、前言、本书简介、符号与约定、第一至第八章全部 76 道题、参考资料。**不设附录，也不设使用说明。**
- **题间留白**：每题之后按该题原解答的排版行数留出书写空间——原解答不超过 5 行的留 4 倍行距，6 至 8 行的留 6 倍，9 行以上的留 8 倍。
- **自足性**：题面中凡指向附录的地方均已就地补全。例如第六章题 15 用到“准一致收敛”，该定义已直接抄入题面，读者无需翻阅正书。
- **封面**：沿用正书版式，主标题下以同款白色副题标明“纯习题册”。
- 两册的题目逐字一致，题号编号方式相同，可对照使用。

## 编译方式

使用 XeLaTeX，在两册各自的目录下作为工作目录编译母文件，跑两遍以生成目录：

```
xelatex 数学分析习题整理.tex   # 在 正书/ 下
xelatex 数学分析纯习题册.tex   # 在 纯习题册/ 下
```

各章文件均可单独编译（文件头带 `\ifdefined\BookMaster` 分支），也可由母文件 `\input` 引入。

## 题目与解答标记

- `【题x】`：普通题目；`【拓展1】`、`【拓展2】`：相关定理或证明方法的扩展。
- **证明**：主要解答；**另解**：可以独立完成论证的另一种方法。
- **注**、**注记**：就近补充条件、记号、结论或思考动机。
- **一点思考**：记录思考动机或试探过程，不替代严格证明。

以上标记只出现在正书中；纯习题册只有题面。
