# 数学分析习题整理

> 一份在南京大学一年级数学分析学习过程中逐步积累形成的笔记式习题整理，面向复习、查阅与二次整理。

本项目按数学分析课程的学习顺序编排，选取较有难度、方法典型或思路新颖的题目，并尽量保留推导过程、解题思路与必要注记。它不以完整覆盖数学分析全部知识点为目标，而是一份持续修订的学习资料。

## 内容概览

- **第一章·数列**：数列收敛、单调性与有界性、递推数列、嵌套根式、组合平均、上下极限及相关极限方法。
- **第二章·实数系基本定理**：上确界、单调子列、Bolzano 定理、Cauchy 收敛准则、闭区间套、有限覆盖与次可乘数列。
- **第三章·函数**：连续性、一致连续性、单侧极限、单调函数、间断点、周期函数与最小正周期。
- **第四章·一元微分学与一元积分学**：Rolle 定理和 Lagrange 中值定理的拓展证明、导数与高阶导数估计、积分零点问题及中值定理构造。
- **第五章·多元微分学与多元积分学**：齐次函数、隐式零点函数、凹性、二元 Riemann 可积性、Hölder 曲线、调和函数、Gauss 公式、曲线积分和球面平均公式。

## 快速开始

- 直接阅读：[数学分析习题整理.pdf](数学分析习题整理.pdf)
- 编译整书：以 [数学分析习题整理.tex](数学分析习题整理.tex) 为入口。
- 独立编译章节：五个 `第一章-*.tex` 至 `第五章-*.tex` 文件均可单独 XeLaTeX 编译。

建议使用安装了 Windows 中文字体的 TeX Live（或兼容的 LaTeX 环境）和 **XeLaTeX**。在仓库根目录连续运行两遍：

```bash
xelatex 数学分析习题整理.tex
xelatex 数学分析习题整理.tex
```

第二遍用于更新目录和书签。编译会生成 `.aux`、`.log`、`.out`、`.toc` 等本地中间文件，无需提交。

## 题目与解答标记

- `【题x】`：普通题目；`【拓展1】`、`【拓展2】`：相关定理或证明方法的扩展。
- **证明**：主要解答；**另解**：可独立完成论证的另一种方法。
- **注**、**注记**：就近补充条件、记号、结论或思考动机。
- **一点思考**：记录思考动机、试探过程或非正式想法，不替代严格证明。

## 来源说明

题目文字未作改动。题目主要来源包括：

- 谢惠民、恽自求、易法槐、钱定边编著的《数学分析习题课讲义》；
- 石亚龙老师的数学分析课堂例题；
- 作者做过的南京大学数学分析期中、期末试题。

由于整理过程较长，且部分题目来自课堂、试卷与个人笔记，目前无法做到逐题溯源。部分证明和讲解依据课堂笔记转载整理。

本仓库仅作学习交流用途，暂不声明额外的开源授权。若相关内容存在来源标注不清或不适合公开展示的问题，欢迎提出，我会及时修订或删除。
